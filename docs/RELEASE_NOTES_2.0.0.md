# v2.0.0

引擎、界面、存档、剧本全部重写为可扩展的模块结构，并新增一部完整的原创悬疑推理互动小说。

## 新内容

- **《雾港旧案》** —— 四部 80 章，242 场景，约 23 万字，4 个结局（退潮 / 暗礁之下 / 灰烬 / 静音）。
  - 每章一处线索推进 + 两个判断型选项，选后进入独立新文本。
  - 结局由玩家全程积累的线索标记判定，推理选错会落到更冷的结局。
  - 结构校验：无重复场景、无悬空跳转、无回头路、无死路、242 场景全部可达。

## 引擎与界面

- 新剧本 DSL（`sc` / `op` / `opFlag` / `opIf` / `opUnless` / `opCount`），写一部新剧本只需一个 `buildScenes()` 与一条注册表条目，UI 不用动。
- 场景运行时状态机（`StorySession`）：逐段推进、条件选项、限时场景、线索标记与计数。
- 打字机按段落长度自动调速，点击可跳过打字，长文本逐段继续，打字时自动滚到最新一行。
- 存档层改为 JSON + SharedPreferences：自动存档、继续游戏、结局收集进度。
- 修复打字机在「点击跳过」与逐字输出竞争时 `StringIndexOutOfBoundsException` 崩溃的问题。

## 兼容性

- 包名 `com.yumoo.diedang`，versionCode 20000，versionName 2.0.0。
- minSdk 24，targetSdk 36，竖屏。
- 安装包 **debug 签名**，可直接安装试用；尚未配置正式发布签名，不适合上架应用商店。
- 旧剧本《梧桐树下的回声》（166 场景 / 9 结局）完整保留，可与新剧本并列选择。
