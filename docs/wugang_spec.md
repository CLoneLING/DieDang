# 《雾港旧案》剧本写作规范（给写作者）

先读 `docs/wugang_bible.md`（设定、人物、真相、标记表、章节目录），再按分配给你的章节写。

## 一、你要产出什么

一个 Kotlin 文件，路径形如
`app/src/main/java/com/yumoo/diedang/story/wugang/Part1A.kt`

内容模板（**逐字照抄结构，只替换正文**）：

```kotlin
package com.yumoo.diedang.story.wugang

fun part1aScenes(): List<Scene> = listOf(
    sc(
        "p1c01",
        """
        正文第一段……

        正文第二段……
        """,
        opFlag("先看锁孔", "p1c01a", "C_MOVED"),
        opFlag("先翻口袋", "p1c01b", "C_BODY1")
    ),
    sc(
        "p1c01a",
        """
        分支正文……
        """,
        op("退出集装箱", "p1c02")
    ),
    sc(
        "p1c01b",
        """
        分支正文……
        """,
        op("站起来", "p1c02")
    )
)
```

可用的函数（已定义在 `Dsl.kt`，同包，不用 import，也不用引入 Scene/Option）：

- `sc(id, text, vararg opts, isEnding = false, timeLimit = 0, endingTitle = null)`
- `op(text, target)`、`op(text, target, condition)`
- `opFlag(text, target, vararg flags, condition)` —— 选中即写入线索
- `opIf(text, target, flag)` —— 已持有该线索才出现的选项
- `opUnless(text, target, flag)` —— 未持有才出现
- `opCount(text, target, flag, counter)`

**不要写 import 行**（`Scene` / `Option` 的 import 一行都不要写，写了会编译失败）。

## 二、语法红线（违反即编译失败）

1. 正文里不许出现 `$`、反斜杠 `\`、三个连续的双引号 `"""`。要写美元就用"美元"。
2. 段落之间空一行即可，不要用 `\n`。
3. 不用 Kotlin 的字符串模板，不写 `${...}`。
4. 只写自己那一个文件；不要改别人的文件；**不要运行 gradle**（编译由主控统一做）。
5. 场景 id 严格按分配：主场景 `p{部}c{章:两位}`，分支 `p{部}c{章}a/b/c`。
6. 每个分支场景必须有且仅有一个出口选项，指向**下一章主场景**；最后一章的分支指向下一部的 `p{部+1}c01`。唯一例外是第四部第 20 章（结局），用 `isEnding = true` 且不给选项。

## 三、结构与字数

- 一章 = 1 个主场景（800—1200 字）+ 2 个（必要时 3 个）分支场景（各 350—600 字）。
- 主场景末尾给 2 个选项，分别进入本章的两个分支场景。
- 两个分支场景的正文**必须完全不同**：给不同的情报、不同的代价、不同的细节。
- 分支里可以再用 `opIf` 塞一个"只有看懂了才问得出口"的额外选项，指向本章第三个分支场景（可选，别每章都用）。
- 每条线索按圣经的标记表打；同一章不要把所有线索都发出去，留白。

## 四、文风

- 第三人称限知，紧贴周砚。只写他能看见听见闻见的东西。
- **删掉所有解释性总结**。不写"他意识到""这说明""换句话说""他明白了"。结论用动作、物件、对白、数据的停顿来交付。
- 犹豫与心理一律动作化：手指停在半空、把烟按灭在空罐里、数了三遍台阶、把杯子挪开一寸、摸耳后那道疤。
- 悬念靠"信息差 + 具体数字"：日期、克数、秒数、第几节指骨、票号、页数。
- 短句。段落短。对白多。少形容词。
- 每章最后一句要留一个没说完的东西（一个人名、一个日期、一件不该在那里的物）。
- 选项文案 ≤ 12 字，是动作或判断（「先看锁孔」「把照片翻过来」），不是情绪（不写「相信他还是怀疑他」）。

## 五、自检清单（写完逐条对照）

- [ ] 每个 `op` 的 target 都存在，且指向更后面的场景（不回头、不成环）
- [ ] 除结局外没有死路；每个分支场景都有出口
- [ ] 两个分支的正文没有重复的句子
- [ ] 本章至少显式推进了一条线索，且与圣经的该章 beat 一致
- [ ] 没有 `$`、`\`、`"""`、`${`
- [ ] 没有 import 行
- [ ] 没有"他意识到/这说明"这类句子
- [ ] 标记名全部来自圣经第五节的表
